# Markdown 写法示例

## 文本与链接

可以使用 **粗体**、*斜体* 和 [外部链接](https://www.markdownguide.org/)。

公开笔记之间可以互相链接：[[快速开始#公开发布|回到发布说明]]。

## 待办事项

- [X] 阅读示例
- [ ] 写下第一篇公开笔记

## 代码

```js
const message = '用 Markdown 写下想法';
console.log(message);
```

## 表格

| 语法 | 用途 |
| --- | --- |
| `# 标题` | 区分内容层次 |
| `- [ ] 任务` | 记录待办 |
| `[[笔记标题]]` | 连接其他笔记 |
