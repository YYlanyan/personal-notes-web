# YYlanyan 的公开笔记

这里保存我主动公开的 Markdown 笔记与示例。本仓库不包含 Notes 程序或私人笔记。

## 用 Notes 编辑

1. 启动 Notes，在左上角切换到「公开笔记」。
2. 直接编辑或新建 Markdown 笔记。
3. 阅读并确认公开清单后，点击「发布到 GitHub」。
4. 也可以直接用任意 Markdown 编辑器修改本仓库中的文件。
