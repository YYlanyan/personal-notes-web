# 快速开始

这篇示例介绍如何使用一个 Markdown 工作空间。你可以在「修改」视图中直接替换示例内容。

## 用 Markdown 写作

一级标题以 `# ` 开始，二级标题以 `## ` 开始。用空行分隔段落。

- 在标题下编辑标签。
- 停止输入后，内容会自动保存到本机文件。
- 阅读 / 修改视图可以同时查看原文和预览。

## 公开发布

「公开笔记」工作空间使用单独的公开仓库。点击发布前可以查看会推送的文件。只有点击发布，工作区内容才会上传。

请勿在这里记录不希望公开的私人内容。公开仓库内容可以被任何人阅读与复制。
